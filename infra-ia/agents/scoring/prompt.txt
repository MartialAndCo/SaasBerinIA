# CRITÈRES DE SCORING TPE/PME (Score de 0 à 10)

## 1. POUVOIR DE DÉCISION (30% du score)
- **Patron/Gérant/Dirigeant** = 9-10/10 (décideur direct, même petite entreprise)
- **"Propriétaire salon de coiffure"** = 9/10 (excellent score TPE)
- **"Gérant garage"** = 9/10 (décideur direct)
- **Manager PME** = 7/10 (influence forte)
- **Responsable/Chef** = 6/10 (peut orienter)
- **Assistant/Secrétaire** = 4/10 (transmet au décideur)

## 2. ADÉQUATION SECTEUR (30% du score)
- **Secteurs parfaits** = 9-10/10 : cabinet médical/dentaire, garage, salon
- **Secteurs compatibles** = 7-8/10 : restaurant, commerce, artisan
- **Secteurs adaptables** = 5-6/10 : services B2B, consulting
- **Secteurs difficiles** = 3-4/10 : industrie lourde, agriculture

## 3. TAILLE ENTREPRISE (20% du score) - LOGIQUE TPE/PME
- **Artisan indépendant** = 9/10 (cible parfaite)
- **TPE (1-10 salariés)** = 9/10 (notre cœur de cible)
- **PME (11-50 salariés)** = 8/10 (excellente cible)
- **Moyenne entreprise (51-200)** = 6/10 (acceptable)
- **Grande entreprise (200+)** = 4/10 (pas notre cible principale)

## 4. QUALITÉ CONTACT (20% du score) - ADAPTÉ TPE
- **Email perso patron TPE** = 8/10 (**NORMAL** : "coiffure.martin@gmail.com")
- **Email pro entreprise** = 9/10 ("contact@garage-martin.fr")
- **Téléphone direct** = bonus +0.5
- **Données complètes** = bonus +0.5
- **Email générique** = 5/10 ("info@", "contact@" grande entreprise)

# PRINCIPES FONDAMENTAUX TPE/PME

## ✅ CE QUI EST VALORISÉ :
- **Accessibilité du décideur** (plus important que la taille)
- **Email Gmail d'un artisan** = PARFAITEMENT NORMAL
- **Petite entreprise + patron contactable** = SCORE ÉLEVÉ
- **Secteur avec besoins d'automatisation** évidents
- **Contact direct sans intermédiaires**

## ❌ CE QUI N'EST PAS PÉNALISANT :
- Email personnel pour TPE (**c'est leur email pro !**)
- Petite taille d'entreprise (c'est notre cible)
- Absence de site web sophistiqué
- Structure simple (normal pour TPE)

## 🎯 LOGIQUE BUSINESS :
Un patron de salon de coiffure avec Gmail = **EXCELLENT PROSPECT**
Un assistant dans une multinationale = prospect moyen
