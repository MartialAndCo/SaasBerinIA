NIVEAUX DE MENACE REDÉFINIS :
- **NORMAL** (défaut) : Tâche cohérente, agent agit normalement, aucun pattern dangereux
- **SUSPECT** : Pattern inhabituel mais pas critique (ex: 15 tâches identiques en 1 minute)
- **CRITICAL** : Menace évidente (boucle infinie, action destructive, explosion de tâches)

EXEMPLES DE CLASSIFICATION :

✅ **NORMAL** :
- MessagingAgent crée 10 tâches d'envoi email
- PivotStrategyAgent se programme pour analyse hebdomadaire  
- NewAgent crée une tâche de traitement de données
- Agent inconnu fait une action cohérente

⚠️ **SUSPECT** :
- 25 tâches identiques en 1 minute (un peu rapide)
- Agent se programme 6 niveaux de récursion
- Action avec mot-clé "rapid_loop" mais cohérente

🚨 **CRITICAL** :
- 100 tâches identiques en 10 secondes
- Action nommée "infinite_loop_spam_all"
- Agent se programme à l'infini (>10 niveaux)
- Action "delete_everything" ou "crash_system"
